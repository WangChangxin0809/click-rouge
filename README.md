# Click Rouge（点击肉鸽挂机小游戏）

一款休闲点击的 Roguelike 挂机小游戏。纯 Web 单页应用（HTML5 Canvas + JavaScript）。

## 玩法概要

- 屏幕上不断出现敌人，点击屏幕任意位置对敌人造成伤害
- 敌人死亡掉落金币，超时未击杀则对玩家造成伤害
- 定时出现 Boss，击败后 N选1 奖励（装备/技能/随从）
- 目标是存活尽可能久，通过肉鸽选择构筑能力

## 技术栈

- HTML5 Canvas 渲染
- Vanilla JavaScript (ES Modules)
- CSS + DOM 叠加 UI
- Web Audio API 程序化音效

## 快速开始

直接在浏览器中打开 `index.html` 即可运行。
